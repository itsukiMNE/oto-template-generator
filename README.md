# UTAU OTO Template Generator v0.04

by itsukiMNE

浏览器本地工具，根据 UTAU Reclist Generator v0.44 的录音表 TXT 与 UTAU BGM Generator v0.9 的 BGM TXT 生成 oto.ini **初始模板**。不分析声音、不自动对齐实际发声，需在 SetParam 中继续手工调整。

## 使用方法

1. 解压整个 ZIP，保持所有文件在同一目录。双击 `index.html`。
2. 选择 **Generate Template**：导入带 `#RECLIST_META` 的录音表 TXT 和 BGM TXT，查看识别模式；没有 Metadata 时手动指定录音类型。
3. 选择需要的 VC、拨音、语尾和 Overlap 选项，再单击「生成预览」。
4. 检查别名、时间和警告，下载 `oto.ini`。
5. **Adjust Existing OTO** 模式：导入已有 `oto.ini`，指定录音类型和 BPM。生成时 `Offset + Preutterance` 的绝对时间保持不变，可选择修改其他参数。

支持 CV（単独音）、連単風、連単術、VCV、CVVC（包括带独立句首行的形式）。Extra 尚未实现。

## 当前时间预设

- 单独 CV：按 5 份样本的统一子音组前置距离，子音线 +0.5 拍，右线 +1.5 拍。
- 連単風：与普通 CV 共用前置距离，子音线 +0.25 拍，右线 +0.9 拍，每音间隔 2 拍。
- 連単術与 CVVC 普通 CV：13 份样本的短子音组前置距离，子音线 +0.2 拍，右线 +0.6 拍。
- 普通 VCV：前置 0.5 拍，子音线 +0.25 拍，右线 +0.65 拍。
- 句首 - X：前置 150ms，子音／右线根据录制形式决定。
- VC：后一个 CV 发声拍点前 0.2 拍；前置 160ms，子音线 +30ms；爆破音右线 +50ms，其他 +75ms；Overlap = Pre × 0.4。
- R：前置 0.4 拍，子音线 +0.4 拍，右线 +0.7 拍；`u R2` 默认从「つ」提取。
- bX：先不在初始模板中生成；等手动调整好 `- X` 后，再通过单独的派生步骤制作（已有 OTO Overlap Editor 可使用）。
- Overlap：依照 UTAU OTO Overlap Editor 的别名分类规则，VC 采用 Pre × 0.4。

## 重复与别名

- CV / VCV 等的重复别名按录音表先后保留 1、2 或不限；第二个开始自动编号。
- VC 每种 Alias 最多生成一个，从录音表最先出现的有效连接提取，集中输出在所有其他原音设定条目之后；未录制的子音组不会生成条目。
- 連単術 VC 默认勾选 K/T/P/S/SH/HY/N/M；VCV 默认勾选 K/T/P/S/SH/HY，N/M 可手动开启。CVVC 自动生成所有实际存在的 VC。
- VCV 拨音 `a ん` 和 `a ん2` 固定生成；其他后缀可选。
- 含「ふゅ／てゅ／でゅ」的 VCV 辅助行不单独生成载体母音音素，`ん` 仍然保留。

## 使用限制与注意事项

- 这是 **v0.04 测试版**：需要用实际录音表、录制 WAV 在 SetParam 中测试，尤其是 CVVC 的不同补充录音排列。
- 目前不读取实际 WAV 音频长度；`Cutoff` 使用负值（从 Offset 计算的右边界）；如果某些发音超出音频长度，需要用户手动修改。
- BGM TXT 支持 sec / msec；按编号 2、3 读取 Recording Start / Vocal Start，事件说明文字不限语言。BPM 优先从 TXT 中的 BPM 字段读取，其次尝试文件名（例如 Jazz-140-D#.txt），无法识别时允许手动填写。计算不自行假设 Recording Start 固定为 1.0 秒。
- 无法识别的音素会显示警告并跳过，不做自动猜测；用户自定义音素需要后续扩展支持。
- 编辑已有 OTO 时未识别的原始行、空行及其位置均保留；bX 在已有文件调整模式中暂时跳过，避免破坏其固定 Offset 600ms 的结构。
- 下载生成新的 `oto.ini`，不会覆盖本机原文件；请选择目标文件夹并自行备份旧 OTO。
- 使用 CP932 导出时，如果别名包含该编码不支持的字符，会提示改用 UTF-8。

## 文件

- `index.html`、`style.css`、`app.js`：页面与交互
- `engine.js`：音节解析、参数生成、已有 OTO 调整
- `sounds.js`、`groups.js`：沿用 Reclist Generator v0.44 的音素定义
- `cp932-map.js`：沿用 Reclist Generator 的日本语 ANSI 导出映射

## v0.03 修订

- BGM TXT 支持 msec 毫秒单位与原有 sec 秒单位。
- 不再依赖英文事件名称，按 OREMO 标号 2（录音开始）、3（正式发声）读取时间。
- BPM 可从 TXT 内容、BGM 文件名提取；缺失时可手动输入。
- 其余 OTO 参数和生成逻辑不变。

## v0.04 修订

- 对 CV、連単風、連単術、CVVC 中的独立母音／「ん」录音，一条 WAV 同时生成句首 `- X` 与普通 `X`。CV 类型兼容不带 `_` 的录音名。
- 两条先行线的 WAV 内绝对位置相隔固定 300ms；各自的 Offset、子音线、右线及 Overlap 按所属录音方式计算。
- VCV 的 `_んん.wav` 保留 `n ん`，但 VC 生成排除目标为「ん」的连接，不产生 `n n`。
- 其他录音行及已有 OTO 调整模式保持不变。
